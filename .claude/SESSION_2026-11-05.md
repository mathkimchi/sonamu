## Decisions log

- Momentum: on lift the target is one of the two rows on screen (the speed only picks which), rather than dampening.
- Natural direction in splits: panes are all visible, so the focus ring is what moves; it follows the fingers
  (`Strip::reversed`). Applets publish `Treeview::shown_at_once` so the root knows, even for a split inside a project.
- Split animation: a focus ring drawn over the panes, its leading edges easing out and trailing ones easing in, so it
  stretches toward the next pane and then catches up.
- File manager: slides between documents like the default view (documents are shown one at a time).
- PDFs: Zathura instead of Okular (fallbacks okular, evince; new `pdf_viewer` setting). Faster start, keyboard driven,
  fits the pid → window matching. Checked it runs as a tile in Sonamu. It draws GTK's own title bar (we have no
  server-side decorations) and its title (the tile's label) is the full path.
- #139: Ctrl+Shift+Q now asks first: a notice in the middle of the active screen, and a second press within 3 s quits
  (closing the window still quits right away). Chose double-press over a yes/no dialog: no focus juggling, works
  while a wl client has the keys.
- #102: a hibernating node lost its saved applet when moved (`DetachedTree` didn't carry `hibernated`), so its
  stand-in stayed forever. `DetachedTree::hibernated` now carries it (and marks the node inactive again).
- #116: command hub `open <applet> [args]` replaces the hub in its node (new `NodeRequest::Replace`, keeps the node's
  children); `open wl <program> [args]` starts the program in its place like a restored wl tile (`StartWl`).
- #143: the root shows notices (`RootNodeApplet::notify`, bottom of the active screen, 6 s, cut at 100 chars). First
  use: settings that fail to load (`settings::subscribe_errors`; the last error is kept, so a startup failure shows
  too). Only errors, not successful reloads: DMS rewrites its settings continuously while a slider is dragged.
- Swipe drawing no longer panics if an end closes mid-swipe.
- From the `.claude` "Issues found" lists: moving a tile while it is "Starting ..." kept the placeholder forever
  (`DetachedTree::awaiting` now), and the file manager resizes its documents when the font size changes.
- #128 (subagent, 7223c43): a sized box inside a rounded pane that covered only part of it (eg the file manager's
  list) dropped the pane's radius, so its background poked past the corner arc. `Clip` keeps the pane's rounded rect
  (`rounded`) apart from the rectangular cut (`area`). The code editor's cursor cell only looked like it (yellow on
  yellow). Text is still only cut to rectangles.
- UI kit (subagent, 03a098c..6bad403): `sonamu_sttk::ui` (metrics, text/spans, rect, frame, `Rows` for drawing
  and hit-testing from one value, scroll helpers). Ported treeview + menu, root frame/notice, file manager, project
  overview, session prompt, pane frames, swipe ring. Command hub / help use char grids and already share helpers,
  so they stay. Screenshots byte-identical; I checked the quit notice and the split ring after the port myself.
- Fixed the one clippy warning (`as_chunks` in sar).
- Swipe "first window shrinks": cause was `DisplayAreaPx` being `u32`, so `from_f32` clamped an element moved above / left
  of the screen to 0 and squashed it into the visible part. Fix: signed px areas (i32).
