## Decisions log

- Momentum: on lift the target is one of the two rows on screen (the speed only picks which), rather than dampening.
- Natural direction in splits: panes are all visible, so the focus ring is what moves; it follows the fingers
  (`Strip::reversed`). Applets publish `Treeview::shown_at_once` so the root knows, even for a split inside a project.
- Split animation: a focus ring drawn over the panes, its leading edges easing out and trailing ones easing in, so it
  stretches toward the next pane and then catches up.
- File manager: slides between documents like the default view (documents are shown one at a time).
- PDFs: Zathura instead of Okular (fallbacks okular, evince; new `pdf_viewer` setting). Faster start, keyboard driven,
  fits the pid → window matching. Checked it runs as a tile in Sonamu. It draws GTK's own title bar (we have no
  server-side decorations) and its title (the tile's label) is the full path.
- Swipe "first window shrinks": cause was `DisplayAreaPx` being `u32`, so `from_f32` clamped an element moved above / left
  of the screen to 0 and squashed it into the visible part. Fix: signed px areas (i32).
