# Settings (#63)

- Config dir `$SONAMU_CONFIG`, else `$XDG_CONFIG_HOME/sonamu`. Executable `settings` → its stdout as JSON (timeout), else `settings.json`. Reference: `examples/config` (the dev machine symlinks it).
- Defaults only in `assets/default_settings.json` (`include_str!`); user JSON deep-merged over. Numbers' sane ranges are `#[schemars(range)]` (schema only: loading doesn't enforce them; the settings editor clamps). `settings_file`: edits the user's JSON (diff from defaults; atomic write through symlinks, mode kept) for the settings editor. Reloads compare with `differs` (keybind group order counts). A field missing there panics in `Settings::default()` (tests catch it). Schema `assets/settings.schema.json` is rewritten by test `schema_is_current` (fails once, commit it).
- `"watch": [paths]`: extra files to watch. Watching is via parent dirs, debounced 100 ms. Loop detection is off (`Watcher::run`): a program changing its own watch files reloads forever.
- `sonamu_common::settings`: `get()`/`reload()`/`subscribe()`; applets get `StandardApplet::settings_changed`. `font_size` and `mipmaps` are mirrored into `sonamu_ui` (it can't depend on `sonamu_common`).
- Reloads notify (#143), retried 10 s; on failure previous settings are kept.
- Non-obvious behavior:
  - `palette.bg` is only for hub/buffer line/help backgrounds (an opaque root background hid wallpaper layers). Other backgrounds: `Palette::raised`/`tinted`, translucent via `with_opacity` (0.8).
  - `always_frame`: a lone pane still gets border/gap/radius.
  - `wallpaper` (#104): `"none"` (what's under shows, eg swaybg), `{"color"}`, `{"image": path}` (covers each screen), `{"shader": {path, scale = 1, fps = 30}}` (GLSL `mainImage`, or WGSL `main_image` for `.wgsl`); paths `~/` or relative to the config dir (`config_path`). Drawn by the runner (`sonamu_sar/CLAUDE.md`). `battery_wallpaper`: the same kinds or `"same"` (default; `BatteryWallpaper(None)`), used while discharging (`Settings::wallpaper_now`).
  - `opacity` (#160): alpha of `ui::with_opacity` (translucent backgrounds, treeview text); mirrored into an atomic on reload (`settings::alpha()`), since drawing asks often. Menus/popups stay opaque.
  - `frames_itself` panes (projects showing panes) aren't framed and grow by `gap`.
  - `keybinds` (#114, #147, #107): named groups (`{"Windows": [binds]}`, help sections) of `{mods, key, shell}` or `{mods, key, command, args}`; key = char, name (`left`, `tab`, `enter`, ...) or evdev code; exact mods; first match wins, groups in order (`all_keybinds`; serde_json `preserve_order`). Defaults are in `default_settings.json`; a user `keybinds` replaces them whole (`parse` drops the default's before merging), so it lists the groups it keeps. One bad entry fails the whole parse; so does a flat list.
    - Shell: runner (`run_binding`), before Luau `keymap.set`; commands go after Luau, through `is_keybind`.
    - Commands: node (`standard_keybind`: `quit`, `close`, `wrap_project`, `toggle_half`, `spawn(program)`, `spawn_sibling(program)`, `swap_sibling(n)`, `spawn_terminal`/`spawn_browser` (+`_sibling`)); root (`RootKeybind`: `help`, `view_root`, `view_parent`, `restore_closed` (#162), `history` (#162: toggles the history side view), `swipe(dir)`; `buffer_mode`: `is_buffer_mode_key`, checked before the buffer line takes keys); `traverse(kind, n?)` (`Traversal::from_args`; while the treeview has keys, Alt ones also work without Alt, but `enter`); runner `pluck_place`, `brightness(step %)` (#158: the screen under the pointer). Test `default_keybinds_are_known`.
  - `terminal`/`browser`/`pdf_viewer` unset: env, else first installed of `TERMINALS`/`BROWSERS`/`PDF_VIEWERS` (`standard_keybinds.rs`).
  - `startup`: run once at start (`run_startup`).
  - `displays` (#158): `{"<Make Model Serial> or <connector>": {position: [x, y], primary, ddc}}`, like niri (`sonamu_ui::winit_backend::layout`); the runner sends it to the DRM backend (`DisplayRequest::SetLayout`).
  - Alacritty theme (`alacritty_theme`): each load writes `opacity`, `font_size` (as pt, ×0.75) and `palette.bg`/`fg` to `$XDG_STATE_HOME/sonamu/alacritty.toml` (only if changed; renamed into place). Alacritty's config imports it (`general.import`) and live reloads.
  - `treeview` (#161): pinned column on `side` (`width` %); unpinned (Alt held after Alt+traversal) floats per `floating`: `center` (`floating_size` %) or `side` (column's place, gap around).
  - `touchpad_tap` (#170): `none` (default) / `single` / `twice` (a tap clicks only within `double_click` of the previous tap's release; lone taps do nothing). libinput tapping (with drag) is always on for touchpads; `sonamu_ui::touchpad_tap::TapFilter` in the DRM backend drops taps per the mode, telling them from physical clicks by asking the kernel (`EVIOCGKEY` on a dup of libinput's fd, `RecordingInterface`) whether a button is down. Mirrored into `sonamu_ui` like `mipmaps`.
  - `history` (#162): `mode` `full` (default: also `history.json` beside the session) / `session` / `none` (stop recording; entries stay), `limit` (100) entries; `.claude/SESSIONS.md`.
- Gap: a settings program's background child holding stdout blocks reading after it exits.
